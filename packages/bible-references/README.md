# @empreinte/bible-references

Copie, sans modification, de `packages/bible-reference-parser` du dépôt
[Bible Strong](https://github.com/smontlouis/bible-strong) (commit `76b2a04`).
L'analyseur lui-même dérive de [bible-passage-reference-parser](https://github.com/openbibleinfo/Bible-Passage-Reference-Parser)
de Stephen Smith, sous licence MIT (voir `LICENSE.md`).

Il transforme un texte comme « Jean 3:16 et Rom 8.28-30 » en références
canoniques OSIS (`John.3.16,Rom.8.28-Rom.8.30`). Empreinte s'en sert pour relier
une Bible physique, une note de journal ou une étude aux passages concernés.
