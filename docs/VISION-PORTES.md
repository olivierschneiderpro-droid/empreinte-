# Empreinte : couche de continuité entre les réalités

> Physique → Empreinte → Numérique → Empreinte → Physique.
> Le numérique prépare et conserve l'empreinte du réel ; le réel donne naissance à cette empreinte.

Le physique n'est pas seulement le papier, les objets ou le carnet : c'est aussi **le lieu**,
**les personnes présentes**, **les écrans**, **les équipements**, **les espaces** et **les actions**
qui se déroulent dans le monde réel. Empreinte relie leurs manifestations physiques et
numériques et fait émerger, autour de chaque réalité, les **portes** utiles : relations,
informations, supports, actions et connexions, au bon moment.

## Règles fondamentales

- Une ressource n'est pas la Parole. Une prédication n'est pas la Bible. Un chant n'est pas la
  Bible. Une interprétation n'est pas le texte. Une Église n'est pas l'application.
- Détection ≠ affichage. Détection ≠ accusation. Le système propose une porte, il ne l'impose pas.
- Interconnexion ≠ fusion : Empreinte relie les systèmes existants sans forcément les remplacer.
- Automatiser seulement par étapes : **observation → proposition → validation → automatisation**.
- Trois mémoires distinctes mais reliées : **Église** (collective), **personne** (personnelle),
  **événement** (réalité commune).
- Le choix des portes se fait *selon* : la réalité, le contexte, les permissions, le risque, la
  finalité (physique, numérique, humaine ou automatisée).

## Le culte comme réalité événementielle

Préparation : passage biblique → prédication → support → événement.

Pendant le culte, tout reste relié au même événement :

- le verset apparaît sur l'écran ; les références sont projetées automatiquement ;
- un QR code ouvre le passage sur chaque téléphone ; chacun prend ses notes ;
- le conducteur envoie le passage suivant ; paroles des chants, annonces, formulaire de prière,
  projet ou collecte ;
- une personne à distance suit le même événement ; le replay conserve passages et éléments.

Parcours type : le pasteur sélectionne Jean 3:16 → écran → téléphones → note personnelle
associée à l'événement → replay + notes après le culte → approfondir → rejoindre un groupe →
revenir physiquement au prochain rendez-vous.

### Micro → action (niveaux de confiance)

1. **Suggestion** : « Détection : Philippiens 4:6-7 [Afficher] [Ignorer] ».
2. **Semi-automatique** : prévisualisation puis validation rapide.
3. **Automatique** : référence clairement reconnue → affichage (Église qui a assez testé).
4. **Régie intelligente** : comprend la structure du culte (chant, prière, prédication,
   annonce…) et prépare les supports au bon moment.

Familles d'intégration à couvrir pour chaque domaine : **communication** (messagerie, groupes,
diffusion, notifications, appels, communautés), **Église physique** (écrans, projecteurs, son,
micros, caméras, régie, lumière, affichage, QR, bornes, imprimantes), **Bible**, **événement**
(calendrier, inscriptions, présence, accueil, salles, bénévoles), **diffusion** (site, réseaux,
streaming, podcast, newsletter), **relation** (prière, rendez-vous, accompagnement),
**organisation** (tâches, responsables, ressources, documents, finances, projets, missions).

Pour chaque type de réalité, la cartographie répond à quatre questions : que peut-on
**recevoir du physique**, **envoyer vers le physique**, **recevoir du numérique**, **envoyer vers
le numérique**, et qu'est-ce qui peut être automatisé entre les deux sans détruire la réalité
humaine servie.

## Les sections (portes de ressources)

Bible · Chants chrétiens · Vidéos · Films · Audio / podcasts · Plans de lecture · Cartes ·
Lieux · Personnes · Églises · Études · Événements · Prière · Formation · Actualités · Outils ·
Missions · Communautés · Création · Diffusion.

Ces sections ne sont pas de simples menus : elles **émergent d'une réalité**. Psaume 23 ouvre
Bible, contexte, lieux, thèmes, chants inspirés, prédications, vidéos, études, groupes. Un chant
ouvre ses paroles, ses passages, son artiste, les Églises qui le chantent… La porte d'entrée
change, le centre reste.
