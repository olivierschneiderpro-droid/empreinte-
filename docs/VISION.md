# Vision d'Empreinte

> Le numérique aide à vivre le réel. Le réel nourrit le numérique. Aucun ne remplace l'autre.

## Le physique devient une réalité traçable sans perdre son existence physique

Une facture physique (client ou fournisseur, numéro 47, date, montant, TVA, lignes,
signature, conditions) est reconnue comme **document physique F-47** et reçoit une
identité numérique : `FAC-2026-0047`.

On garde la distinction entre :

```
Document physique original ↕ Représentation numérique ↕ Données structurées ↕ Relations
```

photo ≠ facture physique · OCR ≠ facture physique · donnée structurée ≠ facture physique.
Ce sont des manifestations d'une même réalité, avec des niveaux de confiance différents.

## Le système propose une méthodologie physique

```
Facture F-47
Identifiant système : FAC-2026-0047
QR / code de liaison : EMPREINTE:FAC-2026-0047
Dossier physique recommandé : Fournisseurs → 2026 → Achats
Emplacement : Classeur 02 → Section B → Pochette 14
```

Sans imposer une seule méthode : numéro, QR code, code-barres, NFC, référence manuscrite,
emplacement physique, couleur de dossier, classement chronologique, par projet, par
fournisseur, ou une combinaison, choisie selon le contexte.

## Les calculs

- **Identité** : quel document ? quel identifiant ? existe-t-il déjà ?
- **Correspondance** : est-ce bien F-47 ? une copie ? une nouvelle version ? un doublon ?
- **Contexte** : client, fournisseur, projet, transaction, période, événement.
- **Emplacement** : où est l'original, sa copie, son archive ? qui l'a ?
- **État** : reçu, vérifié, payé, remboursé, annulé, archivé, contesté.
- **Preuve** : photo originale, OCR, signature, pièce comptable, transaction bancaire, validation humaine.
- **Relations** : facture → commande, paiement, fournisseur, projet, stock, produit, mission.

## Détecter les incohérences, sans conclure trop vite

- Physique 1 250 € / numérique 1 520 € → incohérence.
- Paiement enregistré sans justificatif bancaire → relation manquante.
- Deux documents physiques portent F-47 → doublon potentiel.
- Enregistré numériquement mais original introuvable → rupture de traçabilité.
- Document physique sans enregistrement numérique → nouvelle réalité à intégrer.

Le système dit : **« Anomalie détectée — vérification nécessaire. »**

## Généralisable à toute réalité

Livre (ISBN, exemplaire, emplacement, état, prêts), équipement (inventaire, série,
responsable, maintenance, garantie), Bible (exemplaire, traduction, édition, notes,
passages étudiés), mission (1000 Bibles : achat, facture, réception, stock, distribution,
preuves), projet (maquette, versions, décisions, tests).

## Concevoir l'organisation physique

« Tu possèdes 600 documents physiques et tu dois retrouver rapidement n'importe lequel. »
Options : A chronologique, B par domaine, C par projet, D hybride + identifiant unique,
comparées selon la fréquence d'utilisation, le volume, le temps de recherche, le risque de
perte, le coût, l'espace, l'accès, la confidentialité, la durabilité, le partage et la
synchronisation numérique.

## Pour chaque réalité

Qu'est-ce qui manque ? Qu'est-ce qui est en double ? Qu'est-ce qui n'est pas relié ?
Qu'est-ce qui est mal identifié ? Qu'est-ce qui risque d'être perdu ? Qu'est-ce qui peut
être automatisé ? Qu'est-ce qui doit rester humain ? Qu'est-ce qui doit rester physique ?
Qu'est-ce qui doit être numérique ? Quelle organisation rendrait l'ensemble plus cohérent ?

```
Réalité → représentation → identification → organisation → relation → action → preuve → expérience → retour → apprentissage
```

## Le nom

**Empreinte** : une empreinte n'est pas la réalité elle-même, mais elle en conserve une
manifestation et le lien avec elle, dans les deux sens (facture papier → empreinte
numérique ; projet numérique → empreinte physique).
